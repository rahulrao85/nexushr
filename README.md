# NexusHR — Enterprise HR Management System

A modern, single-page HRMS built with React 19 + Vite. Manage your workforce — employees, payroll, hiring, job changes, and terminations — all from one dashboard.

## Features

- **Dashboard** — At-a-glance HR metrics (headcount, turnover, team distribution)
- **Employee Management** — Full employee directory with search, filter, and detailed profiles
- **Payroll** — Salary breakdowns, deductions, and net pay for each employee
- **Hiring** — Streamlined candidate-to-employee onboarding workflow
- **Job Changes** — Promotions, transfers, and role changes with effective dating
- **Terminations** — Offboarding with compliance data
- **Mock Data** — 100+ realistic employee records across India, US, and UK offices

## Tech Stack

- **React 19** with hooks-based state management (Context API)
- **Vite 8** for near-instant HMR and optimized builds
- **Custom UI component library** (Button, Card, Modal, Table, Stepper, Avatar, Input)
- **Zero external UI dependencies** — all components hand-built

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Build for Production

```bash
npm run build
npm run preview
```
